# APEX Launch Blockers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the seven problems the 2026-11-17 review found that would stop APEX from launching: dead AI features, spoilers on the Watch page, missing link previews, the dead Live page, phone layout problems, an early Google sign-in prompt, and a sign-up button that never says what you get.

**Architecture:** Ten small PRs, each from a fresh `main`, each independently testable. Backend AI calls move behind one client with an optional fallback provider and are pre-generated by the hourly sync instead of on first page view; the agent gets a capacity breaker it reports through `/health`. Frontend logic goes into pure `src/lib/*.ts` functions with vitest tests; component changes are verified in headless Chrome with a small CDP script added in Part 0.

**Tech Stack:** FastAPI + Motor (backend, Python 3.11), deepagents/LangGraph agent, Next.js 16 App Router + React 19 + Tailwind v4 (frontend), `next/og` for images, vitest (node env), pytest, Cloud Run + Cloud Build.

**Spec:** The review delivered in-session on 2026-11-17, scoped by the owner on 2026-11-19. The scoped items are restated in "Spec" below, since there is no separate spec file.

### Task A1.1: One LLM client with an optional fallback (branch `ai/llm-fallback`)

**Files:**
- Create: `backend/app/llm.py`
- Test: `backend/tests/test_llm.py`

**Interfaces:**
- Produces:
```python
@dataclass
class StreamResult:
    provider: str | None = None   # "ollama" | "fallback" | None
    complete: bool = False        # True only when the provider closed the stream cleanly
    failure: str | None = None    # "unconfigured" | "capacity" | "error" | None (last failure seen)

async def stream_text(system_prompt: str, user_content: str, *, model: str | None = None,
                      temperature: float = 0.2, result: StreamResult | None = None,
                      timeout_s: float = 180.0) -> AsyncIterator[str]

def _make_client(timeout_s: float) -> httpx.AsyncClient   # the one place tests patch
def fallback_configured() -> bool
```
- Env read at call time: `OLLAMA_API_KEY`; `LLM_FALLBACK_BASE_URL` (e.g. `https://api.groq.com/openai/v1`), `LLM_FALLBACK_API_KEY`, `LLM_FALLBACK_MODEL`. The fallback is configured only when all three are non-empty.

Behaviour:
- **Primary:** `POST https://ollama.com/api/chat` with `{"model", "messages":[system,user], "stream":true, "options":{"temperature"}}` and `Authorization: Bearer`. Parse NDJSON. Yield `message.content` only, never `message.thinking`. `done: true` sets `complete`.
- **Failure classes:** no key → `unconfigured`; HTTP 402 or 429 → `capacity`; any other non-200, an `httpx.HTTPError`, or an in-stream `{"error": …}` → `error`.
- **Fallback:** runs only when the primary failed *and had yielded zero characters*. `POST {base}/chat/completions` with `{"model": LLM_FALLBACK_MODEL, "messages", "stream": true, "temperature"}`, parsing SSE `data:` lines. Yield `choices[0].delta.content` only (ignore `reasoning` and `reasoning_content`). `complete` is set on `data: [DONE]` or a non-null `finish_reason`.
- **Partial primary:** if the primary yielded text and then broke, stop there: `complete=False`, no fallback.
- Never raises. One log line per failure: `print(f"LLM {provider} failed: {failure} (HTTP {status})")`.
