# APEX — frontend

The Next.js App Router frontend. **See the [repository README](../README.md)**
for what this project is, how the pieces fit together, and how to run it.

Quick start, assuming a backend is already reachable:

```bash
npm install
npm run dev
```

You will need `frontend/.env.local`. All five variables are listed in the root
README's *Local development* section — the app runs with two of them, but the
Live page and the Pitwall Assistant need the other three.

```bash
npm run build && npm run lint
```
